Oxygen Isotope Thermometry: Opx-Cpx¶

Fractionation Equation¶

The temperature-dependent oxygen isotope fractionation between Opx and Cpx is given by:

Δ18OOpx-Cpx=δ18OOpx−δ18OCpx\Delta^{18}\text{O}_{\text{Opx-Cpx}} = \delta^{18}\text{O}_{\text{Opx}} - \delta^{18}\text{O}_{\text{Cpx}}Δ18OOpx-Cpx​=δ18OOpx​−δ18OCpx​
(1)

where:

  • Δ18OOpx-Cpx\Delta^{18}\text{O}_{\text{Opx-Cpx}}Δ18OOpx-Cpx​ is the fractionation (‰)

  • δ18OOpx\delta^{18}\text{O}_{\text{Opx}}δ18OOpx​ and δ18OCpx\delta^{18}\text{O}_{\text{Cpx}}δ18OCpx​ are the isotope values of the minerals.

Temperature Calibration¶

The fractionation factor α\alphaα relates to temperature (TTT in Kelvin):

1000ln⁡αOpx-Cpx=A×106T2+B1000 \ln \alpha_{\text{Opx-Cpx}} = \frac{A \times 10^6}{T^2} + B1000lnαOpx-Cpx​=T2A×106​+B
(2)

Common Calibrations:¶

  1. Matthews et al. (1983):

    1000ln⁡αOpx-Cpx=1.88×106T2−3.131000 \ln \alpha_{\text{Opx-Cpx}} = \frac{1.88 \times 10^6}{T^2} - 3.131000lnαOpx-Cpx​=T21.88×106​−3.13
    (3)

  2. Chiba et al. (1989) (recommended):

    1000ln⁡αOpx-Cpx=1.57×106T2−0.531000 \ln \alpha_{\text{Opx-Cpx}} = \frac{1.57 \times 10^6}{T^2} - 0.531000lnαOpx-Cpx​=T21.57×106​−0.53
    (4)

Solving for Temperature¶

Rearranging the Chiba et al. (1989) equation:

T(K)=1.57×106Δ18OOpx-Cpx+0.53T(K) = \sqrt{\frac{1.57 \times 10^6}{\Delta^{18}\text{O}_{\text{Opx-Cpx}} + 0.53}}T(K)=Δ18OOpx-Cpx​+0.531.57×106​​
(5)

Convert to °C:

T(°C)=T(K)−273.15T(°C) = T(K) - 273.15T(°C)=T(K)−273.15
(6)

Example Calculation¶

Given:

  • δ18OOpx=5.6 ‰\delta^{18}\text{O}_{\text{Opx}} = 5.6\ ‰δ18OOpx​=5.6 ‰

  • δ18OCpx=5.2 ‰\delta^{18}\text{O}_{\text{Cpx}} = 5.2\ ‰δ18OCpx​=5.2 ‰

  1. Calculate Δ18O\Delta^{18}\text{O}Δ18O:

    Δ18OOpx-Cpx=5.6−5.2=0.4 ‰\Delta^{18}\text{O}_{\text{Opx-Cpx}} = 5.6 - 5.2 = 0.4\ ‰Δ18OOpx-Cpx​=5.6−5.2=0.4 ‰
    (7)

  2. Compute temperature (Chiba calibration):

    T(K)=1.57×1060.4+0.53=1.688×106≈1298 KT(K) = \sqrt{\frac{1.57 \times 10^6}{0.4 + 0.53}} = \sqrt{1.688 \times 10^6} \approx 1298\ \text{K}T(K)=0.4+0.531.57×106​​=1.688×106​≈1298 K
    (8)

  3. Convert to °C:

    T(°C)=1298−273.15≈1025°CT(°C) = 1298 - 273.15 \approx 1025°CT(°C)=1298−273.15≈1025°C
    (9)

Result: Crystallization temperature ≈ 1025°C.

import numpy as np

def calculate_opx_cpx_temp(d18O_opx: float, d18O_cpx: float, calibration: str = "Chiba") -> float:
    """
    Calculate crystallization temperature using Opx-Cpx δ¹⁸O fractionation.
    
    Parameters:
        d18O_opx (float): δ¹⁸O of orthopyroxene (‰).
        d18O_cpx (float): δ¹⁸O of clinopyroxene (‰).
        calibration (str): "Chiba" (default) or "Matthews".
    
    Returns:
        Temperature in °C.
    """
    delta = d18O_opx - d18O_cpx
    
    if calibration == "Chiba":
        A, B = 1.57e6, 0.53
    elif calibration == "Matthews":
        A, B = 1.88e6, 3.13
    else:
        raise ValueError("Calibration must be 'Chiba' or 'Matthews'.")
    
    T_kelvin = np.sqrt(A / (delta + B))
    T_celsius = T_kelvin - 273.15
    
    return T_celsius
# Example usage
d18O_opx = 6.621231   # ‰
d18O_cpx = 6.225780   # ‰
temp = calculate_opx_cpx_temp(d18O_opx, d18O_cpx, calibration="Chiba")
print(f"Calculated Temperature: {temp:.1f}°C")

import numpy as np
import matplotlib.pyplot as plt

# Define temperature range (in Kelvin)
T = np.linspace(273.15, 1600, 1000)  # from 0°C to ~927°C

# Define geothermometry function
def ln_alpha(A, B, T):
    return A * 1e6 / T**2 + B

# Define mineral pairs with A and B values
mineral_pairs = {
    "Kuvars–Kalsit": (0.38, 0),
    "Albit-Kalsit": (-0.56, 0),
    "Anortit-Kalsit": (-1.61, 0),
    "Diyopsit-Kalsit": (-2.37, 0),
    "Forsterit-Kalsit": (-3.29, 0),
    "Forsterit-Kalsit": (-5.91, 0)
}

# Compute x-axis: 10⁶ / T²
x = 1e6 / T**2

# Plot
fig, ax = plt.subplots(figsize=(6, 7))

for label, (A, B) in mineral_pairs.items():
    y = ln_alpha(A, B, T)
    ax.plot(x, y, label=label)

ax.set_xlabel("10⁶ / T² (K⁻²)")
ax.set_ylabel("1000 lnα")
ax.set_title("Oxygen Isotope Geothermometry")
ax.set_xlim(0.1, 1.5), ax.set_ylim(-10, 15)
ax.legend()

# Add a secondary x-axis on top for Temperature (°C)
def T_to_x(T):
    return 1e6 / T**2

def x_to_T(x):
    return (1e6 / x)

secax = ax.secondary_xaxis('top', functions=(x_to_T, T_to_x))
